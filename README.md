This project includes three main pages:

- **Projects Page** – A showcase of my completed projects

## Features
- Multi-page website structure using HTML
- Styled layout using CSS for improved design and readability
- Navigation between pages for a smooth user experience
- Clean and simple UI design focused on clarity

## Technologies Used

- CSS3

## Purpose
The purpose of this project was to strengthen my understanding of web development fundamentals, including page structuring, styling, and creating a more visually appealing user interface.
